# 0.1.18

- Mods can add a check mark to the Controls list for a boolean preference (`RebindApi.RegisterToggle`), in both the keyboard/mouse and controller views.
- FATE Aiming 0.2.0 uses this for "Invert up/down aim".
- Existing bindings and saved settings are unchanged.

# 0.1.17

Public release packaging, supplied emblem, documentation and download-source links.
Gameplay behavior is unchanged from the user-tested 0.1.16 build.
Permanent Thunderstore identity: MikhailKillsZombies-Rebinds_Mod.

# 0.1.16

- Added a wheel-zoom checkbox. On: wheel zoom is active and zoom bindings are hidden.
- Added separate controller camera left/right and up/down inversion checkboxes.
- Corrected default horizontal camera direction; options also work with swapped sticks.
- Preserved saved bindings and kept controller menu navigation independent.

# Earlier versions

Introduced the native-style Controls editor, primary/secondary bindings,
clear/reset and conflict swapping, automatic keyboard/controller view switching,
controller glyphs/navigation, stick swapping, modular live-action registration,
and directional wheel zoom handling.
