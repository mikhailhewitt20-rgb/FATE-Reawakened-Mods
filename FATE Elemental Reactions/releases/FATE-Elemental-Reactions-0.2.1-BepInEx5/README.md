# FATE Elemental Reactions 0.2.1

Standalone elemental tester for FATE: Reawakened. No co-op implementation or dependency.

## Elements

- Existing Ruby gems apply flat Fire damage (Pyro).
- Existing Opal gems apply flat Ice damage (Cryo).
- Existing Turquoise gems apply flat Electrical damage (Electro).
- Gem descriptions show weapon damage and corresponding armor resistance.
- Element indicators appear above the entity affected by an elemental hit.
- Press **F8** in Town of Grove to spawn stationary, invulnerable elemental slimes and a resistance-free training target in the field south of the dungeon portal.
- The first time an existing character loads, the package grants six empty socketable swords, alternating between two and six sockets.

This build does not add separate gem item types or implement elemental reactions. It uses the gems already in the game.

## Install

Import the zip as a local package in r2modman or Thunderstore Mod Manager for FATE: Reawakened. Requires BepInExPack 5.4.2305. Launch the modded profile and load an existing character.
