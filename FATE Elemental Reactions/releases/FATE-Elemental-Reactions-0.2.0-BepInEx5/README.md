# FATE Elemental Reactions 0.2.0

Standalone elemental test mod for FATE: Reawakened. No co-op implementation or dependency.

## Elements

- Existing Ruby gems apply flat Fire damage (Pyro).
- Existing Opal gems apply flat Ice damage (Cryo).
- Existing Turquoise gems apply flat Electrical damage (Electro).
- Gem descriptions show weapon damage and corresponding armor resistance.
- Element indicators appear above the entity affected by an elemental hit.

This build does not add new gem item types or implement reactions. It uses the gems already in the game. A one-time command in the package spawns stationary, invulnerable elemental slimes and a resistance-free target in the field south of the Grove dungeon portal on first Grove load.

## Install

Import the zip as a local package in r2modman or Thunderstore Mod Manager for FATE: Reawakened. Requires BepInExPack 5.4.2305. Launch the modded profile and load an existing character in Grove.
