# FATE: Reawakened — first-party mods

This repository collects first-party mod projects by MikhailKillsZombies. Each project remains in its own folder, with source, documentation, and available package/release snapshots. Unreleased snapshots are retained here for GitHub.

## Included

- FATE Aiming Mod
- FATE Elemental Reactions
- FATE Mod Menu
- FATE Music Player (the mod only)
- FATE Permanent Storage
- FATE Quick Spell Mod
- FATE Rebind
- FATE Vortex Extension

## Excluded

- Projects and code authored by PartGhost, including the shared co-op prototype and co-op fork built on PartGhost's foundation.
- Genshin and Skyrim music packs; the Music Player mod remains included.
- The experimental Mod Loader folder because its saved preview includes co-op files and project ownership/status is unclear.
- Generated build output, local test instances/saves, and tool dependencies.

Some projects use local game/BepInEx assemblies for builds. See each project README and build script for prerequisites. `FILE-MANIFEST.csv` lists staged files and hashes.
