# FATE: Reawakened mods

Free mods and tools for FATE: Reawakened by MikhailKillsZombies. Each project has its own repository for browsing source, version history, and GitHub releases. This collection repository provides an overview and links to each project.

## Installing mods

For supported packages, install and manage mods through **2rmodman** using **Thunderstore**. The release files marked for Thunderstore are intended for that workflow. Each mod's own README lists any additional notes or prerequisites. GitHub also keeps source code and older or unreleased snapshots for reference.
