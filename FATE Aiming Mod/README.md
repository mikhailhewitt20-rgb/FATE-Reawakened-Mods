# FATE Aiming Mod

Target-mode aiming for FATE: Reawakened.

Install and manage the mod through **2rmodman** from **Thunderstore**. See the project documentation for requirements and configuration. This repository includes source and version snapshots, including unreleased versions. Browse [GitHub Releases](https://github.com/mikhailhewitt20-rgb/FATE-Aiming-Mod/releases) for published packages.
